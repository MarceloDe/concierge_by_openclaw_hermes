The proof discipline is enforced, not aspirational

docs/NON_MOCKED_PROOF_RULES.md defines a readiness ladder — contract_ready → local_live_ready → remote_live_ready → external_blocked → production_candidate → production_ready — and forbids naming a fixture a live proof. The code honors it. Of 438 tests, the 7 skips each print a loud precondition naming the exact env var and the real resource they need. None silently pass.

The single highest-risk item on this page

The default LangGraph checkpointer is MemorySaver. A pending consent interrupt does not survive a process restart. The guard is real — a production runtime profile boot-throws non_durable_interrupts_in_production_profile rather than running unsafely — but that means today there is no configuration in which you can both run a production profile and pause for consent. The Postgres checkpointer that resolves this is named as a Phase 91 work item and is not signature-gated. It is the one substantial piece of engineering available to do right now without waiting on you.
